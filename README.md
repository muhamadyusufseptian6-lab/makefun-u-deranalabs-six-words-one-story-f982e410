A complete story told in exactly six words, written by a small deterministic
Node program that writes the story to `/output/entry.txt`.

## The story

> I forgave him; he never asked.

Six words. A hurt, a grace offered — and the quiet turn: it was never
asked for, so the forgiveness lands on no one but the forgiver.

## How it works

`main.ts` (Node 22, standard library only) writes the six-word story to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.
